# Grouping GA App

参加者同士の相性行列をもとに、遺伝的アルゴリズムで班内相性の総和が高い班分けを探索するFlask製Webアプリです。

## 主な機能

- 参加者名、班数、1班あたりの人数の入力
- 上三角のみ編集できる相性行列（下三角は自動補完）
- UTF-8 CSVの相性行列読み込みと入力検証
- GAによる班分け、評価スコア表示、同条件での再実行
- サンプルデータ、乱数シードによる再現

## 起動方法

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run --debug
```

ブラウザで `http://127.0.0.1:5000` を開きます。

## CSV形式

参加者数と同じサイズの正方・対称行列をUTF-8で用意します。対角成分は0です。行名・列名を含む形式にも対応します。`static/sample_matrix.csv` を参照してください。

## 評価とGA

各班の全ペアについて相性値を一度ずつ合計し、全班の総和を最大化します。個体は参加者の順列で表現し、一定人数ごとに班へ分割するため、すべての候補が人数制約を満たします。選択はトーナメント方式、交叉は順序交叉、突然変異は2名の入れ替え、エリート保存を使用します。

GAは準最適解を探索する手法であり、完全最適解を保証しません。実在する人間関係データをリポジトリへコミットしないでください。
