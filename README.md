# grouping-ga-app

参加者同士の相性行列をもとに、遺伝的アルゴリズムを用いて班分けを最適化するWebアプリです。

## 概要

本アプリは、サークルやイベントにおける班分け作業を支援することを目的としたWebアプリです。

参加者同士の相性を数値化した相性行列を入力し、遺伝的アルゴリズム（GA）を用いて、班内の相性スコアが高くなる班分け案を生成します。

## 作成背景

サークルやイベントの班分けでは、参加者同士の相性や、同じ班にしたい・同じ班にしたくない組み合わせを考慮する必要があります。

しかし、参加者数が増えると組み合わせ数が膨大になり、手作業で望ましい班分けを作成することは難しくなります。

そこで、班分けを組み合わせ最適化問題として捉え、遺伝的アルゴリズムを用いて、条件を満たしながらより良い班分け案を探索するアプリを制作しました。

## 主な機能

- 参加者名または参加者IDの入力
- 班数・1班あたりの人数の設定
- 相性行列の入力
- 入力された相性行列に基づくGAの実行
- 班ごとのメンバー表示
- 班分け結果の評価スコア表示
- サンプルデータによる動作確認

## 相性行列について

本アプリでは、参加者同士の関係を相性行列として表現します。

- 正の値：同じ班にしたい関係
- 負の値：同じ班にしたくない関係
- 0：特に指定のない関係

例えば、参加者Aと参加者Bの相性が高い場合は正の値を、同じ班にしたくない場合は負の値を設定します。

この相性行列をもとに、GAが班分け案を探索します。

## 評価関数

評価関数では、各班に含まれる参加者ペアの相性値を合計し、班分け全体のスコアを計算します。

基本的な評価値は以下のように定義します。

```text
評価値 = 各班内に存在する全ペアの相性値の総和

さらに、同じ班にしたいペアや、同じ班にしたくないペアをより明確に扱うため、通常の相性スコアとは別に、ボーナス・ペナルティを加える設計を検討しています。

評価値
= 班内ペアの相性スコアの総和
+ 同班希望ペアへのボーナス
- 分離希望ペアへのペナルティ

当初は、特定の条件を満たした場合に相性値のオーダーを引き上げる方式を考えていました。しかし、一般的なWebアプリとして利用する場合、どの条件でオーダーを引き上げるかをユーザーに入力させる必要があり、評価値の意味も複雑になります。

そのため、通常の相性評価と、同班希望・分離希望の条件を分け、ボーナス・ペナルティとして扱う方針に変更しました。

この設計により、評価関数の意味を明確にし、利用場面に応じて条件を調整しやすくすることを目指しています。

## 工夫した点
1. 班分けを組み合わせ最適化問題として定式化した点

手作業で行っていた班分けを、参加者同士の相性行列と班分け結果の評価関数によって数値的に扱えるようにしました。

これにより、「なんとなく良さそうな班分け」ではなく、評価スコアに基づいて班分け案を比較できるようにしています。

2. 評価関数の設計を見直した点

当初は、自分のサークル内で使うことを想定し、特定条件を満たした場合に相性値のオーダーを引き上げる方式を考えていました。

しかし、一般的なWebアプリとして利用する場合、その方式では条件設定や評価値の説明が複雑になると考えました。

そこで、通常の相性スコアと、同班希望・分離希望の条件を分け、ボーナス・ペナルティとして評価関数に加える設計に見直しました。

この経験から、アルゴリズムは単に動けばよいのではなく、利用者や利用場面に応じて設計を変える必要があると学びました。

3. GAロジックと画面処理を分離した点

ga.py にGAの計算処理をまとめ、app.py やHTML側とは分離しました。

これにより、画面構成を変更した場合でも、GAの本体部分を再利用しやすくしています。

開発におけるAI活用

本アプリの実装では、Codexなどの生成AIを活用しました。

ただし、課題設定、相性行列を用いた問題の表現、評価関数の設計、要件定義については自分で整理し、生成AIは主にFlaskやJavaScriptの実装補助、コード分割、入力処理の整理に用いました。

AIが生成したコードについては、処理の流れを確認し、要件に合うように修正しながら実装を進めています。
