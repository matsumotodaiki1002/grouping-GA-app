# grouping-ga-app

参加者同士の相性行列をもとに、遺伝的アルゴリズムを用いて班分けを最適化するWebアプリです。

## 概要

本アプリは、サークルやイベントにおける班分け作業を支援するWebアプリです。  
参加者同士の相性を数値化した相性行列を入力し、遺伝的アルゴリズムを用いて、班内の相性スコアが高くなる班分け案を生成します。

## 作成背景

サークルやイベントの班分けでは、参加者同士の相性や避けたい組み合わせを考慮する必要があります。  
しかし、参加者数が増えると組み合わせ数が膨大になり、手作業で望ましい班分けを作成することは難しくなります。

そこで本アプリでは、班分けを組み合わせ最適化問題として捉え、GAを用いて準最適な班分け案を探索します。

## 主な機能

- 参加者名の入力
- 班数・1班あたりの人数の設定
- 相性行列の入力
- 上三角部分の入力に基づく相性行列の自動補完
- CSVによる相性行列の読み込み
- 遺伝的アルゴリズムによる班分け生成
- 班ごとのメンバー表示
- 評価スコアの表示

## 相性行列について

相性行列では、参加者同士の関係を数値で表します。

- 正の値：同じ班にしたい関係
- 負の値：同じ班にしたくない関係
- 0：特に指定のない関係

本アプリでは、相性は対称であると仮定します。  
そのため、ユーザーは相性行列の対角より上側のみを入力し、下側はシステム側で自動補完します。
